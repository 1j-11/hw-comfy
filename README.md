# 心得
原本想用成黑白漫畫風格的畫面，但是試了3、4次不同的提示詞都沒辦法有我想像中的效果，
不是奇怪的臉型，就是眼睛變得超大超詭異，像早期少女漫畫一樣，雖然最後成品也是，哈哈
還有一開始上傳的圖像素太高，筆電跑到一半就當了，說GPU(還是CPU?)不夠用，
後來改成低像素的圖就可以跑完了，雖然畫質有點差，但還是可以看出原本的樣子，
算是有達到我想要的漫畫效果。
